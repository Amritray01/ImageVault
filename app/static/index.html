Dual Hashing Verification

SHA-256 Digest

Generates a 256-bit cryptographic digest of raw uploaded bytes. Guaranteed bit-for-bit duplicate detection and S3 upload integrity verification.

pHash (DCT 64-bit)

Computes perceptual frequency coefficients using 2D Discrete Cosine Transform. Detects visual similarities and re-saved/cropped versions via Hamming distance.

Metadata Privacy Scrubbing

Consumer cameras & smartphones embed sensitive EXIF metadata. ImageVault parses technical data into structured records while ensuring stored JPEG assets contain zero leaked GPS coordinates.

3. Pillow JPEG Engine
